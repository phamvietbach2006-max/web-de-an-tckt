# Website Trình Bày Đề Án Tái Cấu Trúc Ban Tổ Chức - Kiểm Tra (TCKT)

Dự án Web tương tác phục vụ trình bày toàn thể Ban và báo cáo Thường trực Ban Chủ nhiệm / Trưởng ban về Đề án Tái cấu trúc bộ máy Ban TCKT.

## 🚀 Triển khai 1-Click lên Render

Nhấp vào nút bên dưới để triển khai tự động lên Render:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/phamvietbach2006-max/web-de-an-tckt)

### Cấu hình thủ công trên Render (nếu không dùng Blueprint):
* **Loại dịch vụ:** Static Site (hoặc Web Service)
* **Repository:** https://github.com/phamvietbach2006-max/web-de-an-tckt
* **Build Command:** npm install (hoặc để trống cho Static Site)
* **Publish Directory:** . (hoặc Start Command: node server.js nếu chọn Web Service)

---

## 💻 Xem và chạy trực tiếp trên máy tính cá nhân (Local)

1. Mở file index.html trực tiếp bằng trình duyệt (Chrome, Edge, Cốc Cốc, Safari...).
2. Hoặc chạy máy chủ Node.js:
   npm install
   npm start
   Sau đó truy cập: http://localhost:3000

## 🌟 Tính năng nổi bật của Website

1. **4 Chế độ Xem linh hoạt:**
   * **1. Báo cáo Lãnh đạo (Presentation Mode):** Tóm tắt trực quan các điểm nhấn lớn nhất (Mục tiêu, 3 Đột phá, 3 Sơ đồ, Cơ cấu 67 nhân sự, chỉ số KPI chính).
   * **2. Toàn văn Đề án (Full Document):** Đầy đủ 100% nội dung 10 mục chi tiết như trong văn bản đề án chính thức.
   * **3. Tra cứu Phân công 12 Đơn vị:** Bộ lọc và tìm kiếm nhanh theo Cụm, xem rõ ai là người phụ trách chính, ai là backup, đơn vị song hành.
   * **4. Bảng tính Thử nghiệm Điểm KPI (100đ):** Thành viên tự kéo thanh trượt chấm điểm và xem xếp loại A, B, C, D kèm quyền lợi tương ứng.

2. **Khả năng Phóng to Cỡ chữ (Font Scaler):**
   * Hỗ trợ 4 mức cỡ chữ (A-, A, A+, A++) cực kỳ tiện lợi khi trình chiếu trên TV phòng họp hoặc máy chiếu hội trường.

3. **Xem Sơ đồ Khổ ngang Sắc nét:**
   * 03 Sơ đồ độ nét cao (300 DPI) được tối ưu hiển thị khổ ngang. Nhấp vào ảnh để mở chế độ phóng to toàn màn hình (Lightbox).

4. **Tải về File Word (.docx):**
   * Nút tải trực tiếp file văn bản chính thức De_An_Ban_TCKT.docx ngay trên thanh tiêu đề.
